# Animation Patterns

Individual animation techniques — transitions, keyframes, transforms, easing — combine into a small set of patterns that appear across virtually every production UI. Learning to recognize and build these patterns means being able to implement most UI animation from first principles.

This level is a pattern library: see the pattern, understand how it's built, modify it for your context.

By the end of this lesson you will be able to build staggered list reveals with CSS animation delays, indeterminate progress bars, pulsing notification badges, and the CSS scaffolding for page transitions.

## Staggered list reveal

Items appear one after another, each slightly delayed. This guides the user's eye through the list and makes bulk-loaded content feel organized rather than overwhelming.

```html
<ul class="stagger-list">
  <li class="stagger-item">🐍 Python Fundamentals</li>
  <li class="stagger-item">⚡ JavaScript</li>
  <li class="stagger-item">🎨 CSS Mastery</li>
  <li class="stagger-item">⚛️ React</li>
  <li class="stagger-item">🗄️ SQL</li>
</ul>
```

```css
body { background: #0f172a; padding: 24px; font-family: system-ui; }
@keyframes reveal {
  from { transform: translateY(16px); opacity: 0; }
  to   { transform: translateY(0); opacity: 1; }
}
.stagger-list { list-style: none; margin: 0; padding: 0; display: flex; flex-direction: column; gap: 8px; }
.stagger-item { background: #1e293b; color: #e2e8f0; padding: 14px 16px; border-radius: 8px; font-size: 14px; font-weight: 600; animation: reveal 400ms cubic-bezier(0.34, 1.56, 0.64, 1) both; }
.stagger-item:nth-child(1) { animation-delay: 0ms; }
.stagger-item:nth-child(2) { animation-delay: 80ms; }
.stagger-item:nth-child(3) { animation-delay: 160ms; }
.stagger-item:nth-child(4) { animation-delay: 240ms; }
.stagger-item:nth-child(5) { animation-delay: 320ms; }
```

`animation-delay` increases by `80ms` per item. `:nth-child()` selects each item individually. The gap creates the stagger. In production, this delay is typically generated by JavaScript when items are dynamic — but for static lists, `:nth-child()` CSS is zero-JS.

## Progress bars

Animated progress bars with different visual styles — determinate (known progress), indeterminate (loading, unknown completion).

```html
<div class="progress-section">
  <div class="prog-label">Python — Level 14 / 36 (39%)</div>
  <div class="prog-track"><div class="prog-bar" style="width: 39%;"></div></div>
  <div class="prog-label">CSS — Loading curriculum</div>
  <div class="prog-track indeterminate"><div class="prog-bar prog-indeterminate"></div></div>
  <div class="prog-label">JavaScript — Complete!</div>
  <div class="prog-track"><div class="prog-bar prog-complete" style="width: 100%;"></div></div>
</div>
```

```css
body { background: #0f172a; padding: 24px; font-family: system-ui; }
.progress-section { display: flex; flex-direction: column; gap: 8px; }
.prog-label { color: #64748b; font-size: 12px; font-weight: 600; }
.prog-track { height: 8px; background: #1e293b; border-radius: 9999px; overflow: hidden; }
@keyframes prog-fill { from { width: 0; } to { /* preserves target width */ } }
.prog-bar { height: 100%; background: #6366f1; border-radius: 9999px; animation: prog-fill 800ms cubic-bezier(0.23, 1, 0.32, 1) both; }
.prog-complete { background: #059669; }
/* Indeterminate */
@keyframes indeterminate {
  0%   { transform: translateX(-100%); width: 60%; }
  100% { transform: translateX(200%); width: 40%; }
}
.indeterminate { position: relative; }
.prog-indeterminate { position: absolute; animation: indeterminate 1.4s ease-in-out infinite; background: linear-gradient(90deg, #6366f1, #8b5cf6); }
```

**CS lens:** The indeterminate bar uses `transform: translateX()` rather than `left`, keeping it GPU-composited. The gradient on the indeterminate bar adds visual interest without extra DOM elements — the `linear-gradient` is a CSS image applied to the `background`.

## Pulsing badge / notification dot

A pulsing ring animation for notification badges — communicates "there is something new here."

```html
<div class="notification-demo">
  <button class="notif-btn">
    Notifications
    <span class="badge">
      <span class="badge-count">3</span>
      <span class="badge-ring"></span>
    </span>
  </button>
  <button class="notif-btn">
    Messages
    <span class="badge badge-green">
      <span class="badge-count">●</span>
      <span class="badge-ring ring-green"></span>
    </span>
  </button>
</div>
```

```css
body { background: #0f172a; padding: 32px; font-family: system-ui; }
.notification-demo { display: flex; gap: 12px; flex-wrap: wrap; }
.notif-btn { background: #1e293b; color: #e2e8f0; border: none; padding: 10px 16px; border-radius: 8px; font-size: 14px; font-weight: 600; cursor: pointer; position: relative; display: flex; align-items: center; gap: 10px; }
.badge { position: relative; display: inline-flex; align-items: center; justify-content: center; }
.badge-count { background: #dc2626; color: white; font-size: 11px; font-weight: 800; border-radius: 9999px; padding: 2px 6px; line-height: 1; position: relative; z-index: 1; }
.badge-green .badge-count { background: #059669; font-size: 8px; }
@keyframes pulse-ring {
  from { transform: scale(0.8); opacity: 0.8; }
  to   { transform: scale(2); opacity: 0; }
}
.badge-ring { position: absolute; inset: 0; border-radius: 9999px; background: #dc2626; animation: pulse-ring 1.5s cubic-bezier(0, 0, 0.2, 1) infinite; }
.ring-green { background: #059669; }
```

The ring starts at `scale(0.8)` (slightly smaller than the badge) and expands to `scale(2)` while fading to `opacity: 0`. The badge itself sits on top via `z-index: 1`, so the ring appears to radiate outward.

**SE lens:** These patterns are implemented in every major UI library — Material UI's `LinearProgress`, Radix UI's `Progress`, and Tailwind UI's notification badge all use the same underlying CSS techniques. Learning them in CSS means you understand how the library components work, not just how to use them — which means you can debug them when they break.

**Common mistakes:**
- Stagger delays above 100ms per item — for lists longer than 5 items, delays accumulate and the last item takes forever. Keep total stagger time under 500ms.
- Using `opacity: 0` as the only hidden state for toast/notification enters — screen readers still announce hidden elements. Use `visibility: hidden` or `aria-hidden` for accessibility.

**Debug tip:** To replay animations in the browser without refreshing, open DevTools → Animations panel → click the replay button. This works for all CSS animations and transitions on the current page.

**Next:** Performance and accessibility — `will-change`, compositor layers, and the `prefers-reduced-motion` media query. Writing animation that's both fast and inclusive.

## Challenge: stagger_reveal

Add staggered animation delays to a list.

1. `@keyframes reveal` — `from { opacity: 0; transform: translateY(12px) }` to `to { opacity: 1; transform: translateY(0) }`
2. `.item` — `animation: reveal 400ms ease both`
3. `:nth-child(1)` through `:nth-child(3)` — delays 0ms, 100ms, 200ms

```html
<ul class="list">
  <li class="item" id="li1">First item</li>
  <li class="item" id="li2">Second item</li>
  <li class="item" id="li3">Third item</li>
</ul>
```

```challenge
body { background: #0f172a; padding: 24px; font-family: system-ui; }

@keyframes reveal {
  /* define from / to */

ul { list-style: none; margin: 0; padding: 0; display: flex; flex-direction: column; gap: 8px; }

.item {
  background: #1e293b;
  color: #e2e8f0;

  border-radius: 8px;
  font-size: 14px;
  font-weight: 600;
  /* add animation */

/* add :nth-child delays */
```

var items = document.querySelectorAll('.item')
assert items.length >= 3
var s1 = getComputedStyle(items[0])
