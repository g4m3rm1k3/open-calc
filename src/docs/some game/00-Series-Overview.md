# PhaserJS Series — Math, CS & Software Engineering Through Game Dev

> Build real games. Learn real concepts. Every lab produces something you can play.

---

## How This Series Works

Each lab adds one complete, playable feature to an evolving game. You never write code you can't immediately test. By the end of the series you'll have built a full arcade game from scratch — and along the way you'll have learned the maths, computer science, and software engineering that power it.

**Tools you need:**
- A text editor (VS Code recommended)
- A modern browser (Chrome or Firefox)
- No install required for the first 4 labs

## Concepts Taught (by category)

### Mathematics
- Vectors (direction + magnitude)
- Trigonometry (sin, cos, unit circle)
- Modulo wrapping
- Distance formula (Pythagorean theorem)
- Linear interpolation
- Delta time

### Computer Science
- The game loop / event loop
- Immediate mode rendering
- Arrays and iteration
- Queues (FIFO) for spawning
- Finite State Machines
- Big-O complexity basics

### Software Engineering
- State objects and separation of concerns
- Named constants over magic numbers
- Observer pattern (event system)
- Strategy pattern (swappable behaviours)
- Single-responsibility functions
- Non-linear, playable-first build order
