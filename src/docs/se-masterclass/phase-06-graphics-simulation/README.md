# Phase 6 — Graphics & Simulation

**Goal:** Understand spatial systems, rendering pipelines, and simulation architecture.
**Runtime:** Browser — Canvas / WebGL / Three.js
**Time estimate:** ~35 hours
**Prerequisites:** All of Phase 5

## What this phase teaches

Graphics and simulation are where math, architecture, and performance all collide.
You will learn the math first (vectors, matrices, transforms), then the rendering
loop, then simulation systems.

The patterns here — ECS architecture, spatial partitioning, render pipelines —
are the same patterns used in AAA game engines, CAD software, and scientific
visualization. They transfer directly.

## Modules

- **Module 1 — Math Foundations** (LAB-67 through LAB-69): Vectors, matrices,
  and coordinate transforms.
- **Module 2 — Rendering** (LAB-70 through LAB-72): Render loops, the Canvas API,
  and the painter's algorithm.
- **Module 3 — Simulation** (LAB-73 through LAB-75): Physics, ECS, and spatial
  partitioning.
- **Module 4 — Mini Projects** (LAB-76 through LAB-79): Four complete graphics
  systems.
