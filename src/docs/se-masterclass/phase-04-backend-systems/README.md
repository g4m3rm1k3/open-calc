# Phase 4 — Backend Systems

**Goal:** Build real networked services.
**Runtime:** Python (FastAPI) + Node.js
**Time estimate:** ~40 hours
**Prerequisites:** All of Phase 3

## What this phase teaches

Phase 4 builds services that other systems talk to. You will understand HTTP
at the protocol level before writing your first route. You will understand
async I/O before using async/await. You will understand message queues before
building a worker.

This order matters: understanding the mechanism before using the abstraction
is what separates engineers who debug confidently from those who guess.

## Modules

- **Module 1 — HTTP Fundamentals** (LAB-44 through LAB-46): The protocol,
  REST design, and authentication.
- **Module 2 — Async Systems** (LAB-47 through LAB-49): Event loop, concurrency
  models, and producer/consumer queues.
- **Module 3 — Mini Projects** (LAB-50 through LAB-55): Six complete backend
  systems.
