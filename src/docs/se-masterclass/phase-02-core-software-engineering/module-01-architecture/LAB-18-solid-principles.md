**Coming in this lab:**
- Single Responsibility: one reason to change
- Open/Closed: open for extension, closed for modification
- Liskov Substitution: subtypes must honor their parent's contract
- Interface Segregation: small interfaces over large ones
- Dependency Inversion: depend on abstractions, not concretions

**Core concept:** The five principles that make code maintainable over time
