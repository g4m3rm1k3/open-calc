# SE Masterclass — LAB-28 — Logging System

> **Status:** Not yet written. See [ROADMAP.md](../../../ROADMAP.md) for the full curriculum.

**Prerequisites:** LAB-27 (Testing Framework)

**Coming in this lab:**
- Log levels: DEBUG, INFO, WARN, ERROR and when to use each
- Structured logging: key-value pairs instead of free-form strings
- Log transports: console, file, remote — the strategy pattern in practice
- Correlation IDs: tracing a request through multiple log lines

**Core concept:** Observability — making system behavior visible after the fact

*This is the capstone of Phase 2. After this lab you will have built systems
that appear in every real codebase: plugins, event buses, commands, undo stacks,
config, serialization, testing, and logging.*
