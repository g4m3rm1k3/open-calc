# Phase 2 — Core Software Engineering

**Goal:** Learn maintainable architecture and reusable design patterns.
**Runtime:** Node.js / TypeScript
**Time estimate:** ~35 hours
**Prerequisites:** All of Phase 1

## What this phase teaches

Phase 1 taught you how computation works. Phase 2 teaches you how to structure
computation so it stays maintainable as it grows.

The central questions are:
- How do you split a system into pieces that can change independently?
- How do you make pieces that can be tested without the whole system?
- How do you design for extension without modifying existing code?

## Modules

- **Module 1 — Architecture Principles** (LAB-17 through LAB-20): SOLID,
  composition, interfaces, and dependency injection.
- **Module 2 — Mini Projects** (LAB-21 through LAB-28): Eight systems that
  appear in every real codebase — plugin systems, event buses, command patterns,
  undo stacks, configuration, serialization, testing, and logging.
