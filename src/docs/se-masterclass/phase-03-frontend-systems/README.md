# Phase 3 — Frontend Systems

**Goal:** Understand how user interfaces are built and why frameworks exist.
**Runtime:** Browser — TypeScript + React
**Time estimate:** ~40 hours
**Prerequisites:** All of Phase 2

## What this phase teaches

Phase 3 starts with the raw DOM — no framework. You will feel the pain of
manual state synchronization before you touch React. That pain is intentional:
it shows you exactly what problem the framework solves.

After the raw DOM module, you build the same systems using React — and you
will understand every abstraction React provides because you saw the problem
it solves.

## Modules

- **Module 1 — Raw DOM** (LAB-29 through LAB-31): createElement, addEventListener,
  and manual state sync. The pain before frameworks.
- **Module 2 — Framework Concepts** (LAB-32 through LAB-36): Reactivity, components,
  state management, rendering pipelines, and virtual DOM.
- **Module 3 — Mini Projects** (LAB-37 through LAB-43): Seven complete frontend
  systems that expose real architectural decisions.
