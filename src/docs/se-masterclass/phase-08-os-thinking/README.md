# Phase 8 — Operating-System Thinking

**Goal:** Understand the abstractions that operating systems provide.
**Runtime:** Node.js / Python
**Time estimate:** ~25 hours
**Prerequisites:** All of Phase 7

## What this phase teaches

Operating systems are the substrate everything else runs on. Phase 8 teaches
you to reason about processes, threads, inter-process communication, and
memory — not by writing kernel code, but by using OS abstractions correctly
at the application level.

Understanding these abstractions prevents entire categories of bugs: race
conditions, deadlocks, memory leaks, and zombie processes.

## Modules

- **Module 1 — Concepts** (LAB-92 through LAB-95): Processes, threads, IPC,
  synchronization, and memory management.
- **Module 2 — Mini Projects** (LAB-96 through LAB-100): Shell, process manager,
  file watcher, memory visualizer, and job scheduler.
