# Phase 5 — Databases

**Goal:** Understand persistence, data modeling, and data integrity.
**Runtime:** SQLite, PostgreSQL, Redis
**Time estimate:** ~30 hours
**Prerequisites:** All of Phase 4

## What this phase teaches

Every system eventually needs persistent data. Phase 5 teaches you how
databases actually work — not just how to write queries, but why indexes
exist, what normalization prevents, what transactions guarantee, and what
consistency means when your data lives on multiple machines.

## Modules

- **Module 1 — Relational** (LAB-56 through LAB-59): Modeling, indexing,
  normalization, and transactions.
- **Module 2 — NoSQL and Consistency** (LAB-60 through LAB-61): When to
  not use a relational database and what you give up.
- **Module 3 — Mini Projects** (LAB-62 through LAB-66): ORM, query engine,
  migrations, caching, and analytics.
