# Phase 7 — Language & Tooling

**Goal:** Understand how programming languages work from the inside.
**Runtime:** Node.js / TypeScript
**Time estimate:** ~35 hours
**Prerequisites:** All of Phase 6

## What this phase teaches

This is the most underrated phase in software education. Developers who
understand parsers, ASTs, and interpreters are dramatically more powerful
than those who don't.

You will build a lexer, a parser, an interpreter, and a compiler from scratch.
Then you will apply those skills to build a linter, a formatter, a static
analyzer, and a code generator — tools that make other developers more productive.

The concepts transfer everywhere: every config file is a DSL, every build tool
is a compiler, every IDE feature is a static analyzer.

## Modules

- **Module 1 — Parsing** (LAB-80 through LAB-82): Tokenization, ASTs, and
  recursive descent.
- **Module 2 — Interpretation** (LAB-83 through LAB-84): Tree-walking interpreters
  and stack-machine bytecode.
- **Module 3 — Mini Projects** (LAB-85 through LAB-91): Seven complete language tools.
