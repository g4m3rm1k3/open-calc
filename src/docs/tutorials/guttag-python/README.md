# Introduction to Computation and Programming Using Python
### A 48-Lesson Curriculum Based on John Guttag's Book

This series follows *Introduction to Computation and Programming Using Python*
(John Guttag, MIT Press, 3rd ed.) using the same lesson schema as the
Scheme/Lisp/Clojure/SICP series. Every lesson is standalone. Real Python 3.12
output in every code block.

**Runtime:** Python 3.12. Open a terminal and type `python` to start the REPL.
Modules 5-6 require numpy, matplotlib, and scikit-learn - installation instructions
are in the first lesson that uses each library.
