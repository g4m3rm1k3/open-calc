# Creative Web Masterclass

Build a stunning personal portfolio site while learning CSS, JavaScript, Canvas 2D, and Three.js from scratch.

## What you build

A single-page portfolio with:
- A Three.js animated scene running full-canvas in the background
- Five scroll sections, each a distinct visual world
- A ribbon navigation that tracks your position and lets you jump between sections
- CSS animations, micro-interactions, and glassmorphism effects
- An interactive particle canvas embedded as a section widget
- A typewriter terminal section
- A full card grid section for project showcases

## How the course works

35 labs. Each lab adds one thing you can see immediately in the browser.
Every concept is defined before it is used. Every step is runnable.

Open each lesson in `lessons/`, then build inside the matching folder in `projects/`.
No npm. No build tool. Open `index.html` in Chrome.

## The 35 Labs

| Phase | Labs | Topic |
|---|---|---|
| 0 — Toolchain | 00–01 | DevTools, Live Server |
| 1 — CSS Foundations | 02–08 | Box model, Flexbox, Variables, Transitions, Animations, Glassmorphism, Typography |
| 2 — JavaScript DOM | 09–13 | DOM selection, Events, Animation loop, Intersection Observer, Parallax |
| 3 — Canvas 2D | 14–16 | Canvas setup, Particle field, Mouse interaction |
| 4 — Three.js | 17–23 | Scene, Geometry, Lighting, Clock, OrbitControls, Raycasting, Background |
| 5 — Visual Design | 24–27 | Color system, Micro-interactions, Visual hierarchy, Scroll reveals |
| 6 — Portfolio Build | 28–34 | Shell, Ribbon nav, Hero, Card section, Canvas section, Terminal section, Polish |

## Files

- `projects/` — the runnable project files for each lab
