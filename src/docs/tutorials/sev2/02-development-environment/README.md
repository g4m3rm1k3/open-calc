# Phase 02: Development Environment

## Overview

Before writing code, you need a properly configured development environment. This phase sets up everything you need:

- Python installation and virtual environments
- VS Code with essential extensions
- Git for version control
- Terminal fluency

> **A good environment makes you more productive. A bad one fights you at every step.**

---

## What You Will Learn

| Topic | Why It Matters |
|-------|----------------|
| Python installation | The runtime for our code |
| Virtual environments | Isolated dependencies per project |
| VS Code setup | Efficient code editing |
| Git basics | Version control and history |
| Terminal fluency | Command-line productivity |

---

## Prerequisites

- Complete [Phase 01: Engineering Foundation](../01-engineering-foundation/README.md)
- A computer running Windows, macOS, or Linux
- Administrator access to install software

## Verification Checklist

After completing this phase, verify:

- [ ] `python --version` shows 3.11 or higher
- [ ] You can create and activate a virtual environment
- [ ] VS Code opens with Python extension working
- [ ] `git --version` shows git installed
- [ ] You can navigate the terminal comfortably
