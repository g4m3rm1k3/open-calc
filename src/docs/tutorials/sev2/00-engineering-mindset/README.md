# Phase 00: Software Engineering Mindset

## Overview

This phase establishes the **mental framework** you need before writing a single line of code. Most tutorials skip this entirely, which is why most self-taught developers struggle to build systems that work at scale.

> **The goal of this phase is to permanently change how you think about building software.**

---

## What You Will Learn

| Topic | Why It Matters |
|-------|----------------|
| The difference between coding and engineering | Coding solves puzzles; engineering builds systems |
| How to read requirements like an engineer | Extract what matters, question what's missing |
| Systems thinking fundamentals | See connections, not just components |
| How engineers make decisions | Trade-offs, constraints, and documentation |

---

## Prerequisites

- No programming experience required
- Willingness to think before doing
- Patience to understand *why* before *how*

---

## When You're Done

You should be able to:
- [ ] Explain why "working code" is not enough
- [ ] Read a requirements document and identify missing information
- [ ] Describe a system in terms of entities, relationships, and invariants
- [ ] Make a decision and document your reasoning
- [ ] Explain why documentation matters
