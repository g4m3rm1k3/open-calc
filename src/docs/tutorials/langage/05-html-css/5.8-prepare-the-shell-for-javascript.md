## Terms used in this lesson

- **Attribute** — per Lesson 5.1's own Terms entry, restated here in
  full: a name/value pair inside an element's own opening tag. Every
  real change this lesson makes is one.
- **`id` attribute** — a real, global HTML attribute giving one specific
  element a real, unique name within the whole document — unlike
  `class` (Lesson 5.5), which many real elements can share at once, an
  `id` value must belong to at most one real element per document. It
  exists so that a specific, individual element — not a whole real
  category of them — can be found and addressed directly, the exact
  real role Lesson 5.1's own diagnostic tooling already relied on
  (`document.getElementById`, described there in prose but never shown
  as code) without this project's own real markup ever having supplied
  one before now.
- **`data-*` attribute** — a real, standard family of HTML attributes,
  any real name after the `data-` prefix, holding real, author-defined
  information with no built-in meaning to a browser at all, meant
  specifically for a page's own real, later scripting. MDN's own
  documentation, fetched and quoted this session, states its real
  purpose directly: "`data-*` attributes allow us to store extra
  information on standard, semantic HTML elements without other hacks
  such as non-standard attributes, or extra properties on DOM." It
  exists because `<article>` itself, per Lesson 5.2's own real
  definition, has no attribute of its own for "which real record is
  this" — `data-*` supplies exactly that, without inventing a fake,
  non-standard attribute name a browser might reject or misinterpret.
- **`dataset` property** — the real, standard way JavaScript reads a
  `data-*` attribute back out of an element. MDN's own documentation,
  fetched and quoted this session, states its real mechanism directly:
  "To get a `data` attribute through the `dataset` object, get the
  property by the part of the attribute name after `data-`." This
  lesson's own real attribute, `data-entry-id`, becomes real, readable
  `element.dataset.entryId` once Phase 6's own real JavaScript exists —
  not shown as code here, per this lesson's own Objects-and-methods
