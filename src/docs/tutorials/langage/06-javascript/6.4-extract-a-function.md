## Terms used in this lesson

- **Function declaration** — real JavaScript syntax, `function name
  (parameters) { body }`, that defines a named, reusable block of code.
  Per MDN's own documentation, fetched and quoted this session, "the
  `function` declaration creates a binding of a new function to a given
  name" — a real, permanent name a program can call by, as many times as
  needed, rather than a block of code that only ever runs once, in
  place, the way Lesson 6.3's own loop body did.
- **Parameter** — a real, named placeholder inside a function's own
  parentheses, standing in for whatever real value is actually passed
  in when the function is called; `entry`, in `createEntryElement
  (entry)`, is one.
- **Return value** — the real value a function hands back to whatever
  code called it. Per MDN's own documentation, fetched and quoted this
  session, a real `return` statement "ends function execution and
  specifies a value to be returned to the function caller" — and, per
  that same documentation, a function that never reaches one "returns
  `undefined`" instead, by default.
- **Function call** — real syntax, `name(arguments)`, that actually runs
  a previously declared function, substituting each real argument for
  its matching parameter.
