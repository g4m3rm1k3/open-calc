# First Principles — Terms & Objects Index

A running lookup: term/procedure/construct → the lesson that gave it real, full first-appearance treatment. Exists so a future session can check whether something is already taught by scanning this table instead of running `grep -ln` across every existing `FP-L0##-*.md` file.

**How to use this, per the handoff's "How a lesson gets built":** before deciding whether the next lesson owes a construct a fresh "Terms introduced" / "Objects and methods" entry or an isolated Concept Isolation Rule lab, check here first. If the entry is present, cite the lesson listed and treat it as reappearing (per the Repetition Rule in `LESSON SCHEMA.md`) — full restatement for a hard concept, silent reuse for basic syntax. **If it isn't here, that does not prove it's new** — this index is being built forward from Lesson 104 onward, not backfilled across Lessons 1–103 in one pass (a retroactive sweep of that size would cost more than the greps it's meant to replace). For anything from Era I–III or the early part of Era IV that isn't listed yet, a targeted `grep` for that *specific* term remains the right fallback — just keep it targeted, not a full-corpus sweep.

**Maintenance rule:** every lesson from 104 onward adds its own new terms/procedures/hard-concept-reappearances to this table as the last step before updating the handoff — a few rows, not a project. Pre-104 lessons get added here opportunistically, only when a session is already touching that lesson for another reason — never as a dedicated backfill pass.
