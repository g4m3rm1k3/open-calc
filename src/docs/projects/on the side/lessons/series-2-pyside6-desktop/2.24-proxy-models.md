## Objects and methods used

**`QSortFilterProxyModel`**

- *What it is:* a real, concrete (not abstract) class from PySide6's
  `QtCore` module — a real, ready-to-use model that itself wraps
  another real model (its own "source"), presenting a sorted and/or
  filtered *view* over that source's own real data, without copying
  any of it.
- *Implementation:* `QSortFilterProxyModel(parent: QObject | None =
  None)`; `setSourceModel(self, model: QAbstractItemModel) -> None`;
  `sort(self, column: int, order: Qt.SortOrder) -> None`;
  `setFilterFixedString(self, pattern: str) -> None`;
  `setFilterCaseSensitivity(self, sensitivity: Qt.CaseSensitivity) ->
  None` — real, confirmed default is `Qt.CaseSensitivity.CaseSensitive`,
  case-sensitive, not the more forgiving default a reader might expect.
- *Its use:* `AssetFilterProxyModel`, this lesson's own real subclass,
  extends this directly.
- *Type:* a class, from `PySide6.QtCore` — a real `QAbstractItemModel`
  (2.19, 2.20) in its own right, meaning `QTableView.setModel` (2.19)
  accepts it exactly the same way it accepts any other real model.
- *Responsibility:* present some subset, in some order, of a real
  source model's own rows — nothing about storing any data itself at
  all; every real value still comes from the source model, every
  single time.
- *Depends on:* a real source model, set via `setSourceModel`.
- *Connects to:* sits directly between a real source model and any
  real view attached to it; automatically observes the source model's
  own real signals (`rowsInserted`, `dataChanged`, 2.20, 2.22) and
  forwards equivalent, correctly-translated ones to whatever view is
  attached to the proxy itself.
- *Shape:* this lesson's own real, central new architectural layer —
  the first time this project's `QTableView` has ever displayed
  anything other than a model it talks to directly.

**`QSortFilterProxyModel.mapToSource`**

- *What it is:* a real method every `QSortFilterProxyModel` carries —
  translates one of the proxy's own row/column indices into the real,
  underlying source model's own index for the identical cell.
- *Implementation:* `mapToSource(self, proxyIndex: QModelIndex) ->
  QModelIndex` — real, confirmed proof: once a proxy sorts or filters,
  its own row `0` frequently does *not* correspond to the source
  model's own row `0` at all.
- *Its use:* `self.proxy_model.mapToSource(current)`, inside `on
  _current_row_changed` (2.23), converting the *proxy's* own current
  index into the real row `self.submitted_assets` actually uses.
- *Type:* an instance method, on `QSortFilterProxyModel`.
- *Responsibility:* answer one precise, real question — which source
  cell does this specific proxy cell actually represent — nothing about
  deciding what's filtered or sorted; that's `filterAcceptsRow` and
  `sort`'s own job.
- *Depends on:* a real, valid proxy index; a real source model already
  set.
- *Connects to:* the exact inverse of `mapFromSource` (not used by this
  lesson's own real landing, but a real, symmetric counterpart);
  called anywhere this project's own code needs to reach `self
  .submitted_assets` starting from an index the *view* handed back.
- *Shape:* the real, required bridge every piece of this project's own
  code touching both the proxy and the real underlying data now needs
  to cross.

**`QSortFilterProxyModel.filterAcceptsRow`**

- *What it is:* a real method every `QSortFilterProxyModel` subclass
  may override — decides, per source row, whether the proxy shows it
  at all.
- *Implementation:* `filterAcceptsRow(self, source_row: int,
  source_parent: QModelIndex) -> bool` — called once per source row,
  any time the proxy needs to recompute what it currently shows; the
  real, built-in default (never overridden by this lesson's own throw
  away labs using the base class directly) checks a single stored
  pattern against one designated column instead.
- *Its use:* `AssetFilterProxyModel.filterAcceptsRow`, this lesson's own
  real, central override — checking both the current category filter
  and the current search text together, in one real method, rather
  than two separate, chained proxies.
- *Type:* an instance method, overridden on `AssetFilterProxyModel`.
- *Responsibility:* answer, for exactly one real source row, whether it
  currently belongs in the proxy's own visible set — nothing about
  *how* the proxy is told to re-check every row; that's `invalidate`
  (below), called separately.
- *Depends on:* `self.sourceModel()`, reachable from inside the
  override, to actually read that row's own real values.
- *Connects to:* called automatically by the proxy's own internal
  machinery, once per source row, whenever `invalidate()` (below) runs.
- *Shape:* the real, central decision point this lesson's own custom
  subclass adds on top of `QSortFilterProxyModel`'s own generic base
  behavior.

**`QSortFilterProxyModel.invalidate`**

- *What it is:* a real method every `QSortFilterProxyModel` carries —
  tells the proxy that its own filtering criteria changed, and every
  row needs re-checking against `filterAcceptsRow`.
- *Implementation:* `invalidate(self) -> None` — real, confirmed,
  non-obvious fact: two similarly-named real methods, `invalidateFilter`
  and `invalidateRowsFilter`, are **both** marked deprecated in this
  project's own installed PySide6 — confirmed directly, by actually
  calling each and observing a real `DeprecationWarning`; `invalidate`
  itself raised none.
- *Its use:* called at the end of both `AssetFilterProxyModel
  .set_search_text` and `.set_category_filter`, this lesson's own real,
  central methods — after either one changes what `filterAcceptsRow`
  would return for some row, but before the proxy has re-checked
  anything.
- *Type:* an instance method, on `QSortFilterProxyModel`.
- *Responsibility:* trigger a full, real re-evaluation of every source
  row against `filterAcceptsRow` — nothing about *what* changed; that's
  entirely this lesson's own two setter methods' own job, run just
  before this call.
- *Depends on:* nothing beyond the proxy already having a real source
  model attached.
- *Connects to:* called by this lesson's own two setter methods;
  triggers `filterAcceptsRow` to run again, for every real row.
- *Shape:* the real, required trigger this lesson's own custom filter
  logic needs — checked, not assumed, since the two more
  obviously-named alternatives turned out to both be deprecated.

```python
from PySide6.QtCore import QAbstractTableModel, QModelIndex, QSortFilterProxyModel, Qt
from PySide6.QtWidgets import QApplication, QTableView

app = QApplication([])


class SimpleModel(QAbstractTableModel):
    def __init__(self, rows, parent=None):
        super().__init__(parent)
        self._rows = rows

    def rowCount(self, parent=QModelIndex()):
        return len(self._rows)

    def columnCount(self, parent=QModelIndex()):
        return 1

    def data(self, index, role=Qt.ItemDataRole.DisplayRole):
        if role == Qt.ItemDataRole.DisplayRole:
            return self._rows[index.row()]
        return None


source = SimpleModel(["Zebra", "Apple", "Mango"])

proxy = QSortFilterProxyModel()
proxy.setSourceModel(source)

table = QTableView()
table.setModel(proxy)

print(proxy.rowCount())
print(proxy.index(0, 0).data())

proxy.setFilterFixedString("an")
print(proxy.rowCount())
print(proxy.index(0, 0).data())

proxy.setFilterFixedString("")
proxy.sort(0, Qt.SortOrder.AscendingOrder)
print([proxy.index(row, 0).data() for row in range(proxy.rowCount())])

proxy_index = proxy.index(0, 0)
source_index = proxy.mapToSource(proxy_index)
print(source_index.row())
print(source.data(source_index))
```

### CS Lens

This is the **Decorator pattern** — wrapping a real object (the source
model) with another object presenting the identical real interface,
adding new behavior (filtering, sorting) without changing the wrapped
object at all, and without the object being wrapped ever needing to
know it's been wrapped. This is a hard concept, worth more than one
real-world connection.

```
Also recognized in: a web framework's own request middleware, wrapping
a real handler function with logging or authentication without
changing the handler itself, a beverage-ordering system's own classic
teaching example (a plain coffee "decorated" with milk, then sugar,
each layer adding behavior around the one before it), a video
streaming service's own subtitle track, overlaying a real video stream
without altering the underlying video file at all
```

### SE Lens

```python
import dataclasses

from PySide6.QtCore import QAbstractTableModel, QModelIndex, QSortFilterProxyModel, Qt
from PySide6.QtWidgets import QApplication, QTableView


class InvalidThingError(ValueError):
    pass


@dataclasses.dataclass
class Thing:
    label: str

    def __post_init__(self):
        if not self.label.strip():
            raise InvalidThingError("label must not be empty")


class ThingsModel(QAbstractTableModel):
    def __init__(self, things, parent=None):
        super().__init__(parent)
        self._things = things

    def rowCount(self, parent=QModelIndex()):
        return len(self._things)

    def columnCount(self, parent=QModelIndex()):
        return 1

    def data(self, index, role=Qt.ItemDataRole.DisplayRole):
        if role in (Qt.ItemDataRole.DisplayRole, Qt.ItemDataRole.EditRole):
            return self._things[index.row()].label
        return None

    def flags(self, index):
        return super().flags(index) | Qt.ItemFlag.ItemIsEditable

    def setData(self, index, value, role=Qt.ItemDataRole.EditRole):
        if role != Qt.ItemDataRole.EditRole:
            return False
        try:
            new_thing = dataclasses.replace(self._things[index.row()], label=value)
        except InvalidThingError:
            return False
        self._things[index.row()] = new_thing
        self.dataChanged.emit(index, index, [role])
        return True


things = [Thing("Zebra"), Thing("Apple"), Thing("Mango")]
source = ThingsModel(things)

proxy = QSortFilterProxyModel()
proxy.setSourceModel(source)
proxy.sort(0, Qt.SortOrder.AscendingOrder)

table = QTableView()
table.setModel(proxy)

proxy_index = proxy.index(0, 0)
print(proxy_index.data())

success = proxy.setData(proxy_index, "Avocado")
print(success)
print(proxy_index.data())
print(things)
```

```python
from PySide6.QtCore import QAbstractTableModel, QModelIndex, QSortFilterProxyModel, Qt
from PySide6.QtWidgets import QApplication, QTableView

app = QApplication([])


class AssetsModel(QAbstractTableModel):
    def __init__(self, rows, parent=None):
        super().__init__(parent)
        self._rows = rows

    def rowCount(self, parent=QModelIndex()):
        return len(self._rows)

    def columnCount(self, parent=QModelIndex()):
        return 2

    def data(self, index, role=Qt.ItemDataRole.DisplayRole):
        if role == Qt.ItemDataRole.DisplayRole:
            return self._rows[index.row()][index.column()]
        return None


class AssetFilterProxyModel(QSortFilterProxyModel):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._search_text = ""
        self._category_filter = "All Categories"

    def set_search_text(self, text):
        self._search_text = text
        self.invalidate()

    def set_category_filter(self, category):
        self._category_filter = category
        self.invalidate()

    def filterAcceptsRow(self, source_row, source_parent):
        model = self.sourceModel()
        name = model.index(source_row, 0, source_parent).data(Qt.ItemDataRole.DisplayRole) or ""
        category = model.index(source_row, 1, source_parent).data(Qt.ItemDataRole.DisplayRole) or ""

        if self._category_filter != "All Categories" and category != self._category_filter:
            return False

        if self._search_text and self._search_text.lower() not in name.lower():
            return False

        return True


source = AssetsModel(
    [
        ("ThinkPad X1", "Laptop"),
        ("Dell Monitor", "Monitor"),
        ("MacBook Pro", "Laptop"),
    ]
)

proxy = AssetFilterProxyModel()
proxy.setSourceModel(source)

table = QTableView()
table.setModel(proxy)

print(proxy.rowCount())

proxy.set_category_filter("Laptop")
print(proxy.rowCount())
print([proxy.index(row, 0).data() for row in range(proxy.rowCount())])

proxy.set_search_text("mac")
print(proxy.rowCount())
print(proxy.index(0, 0).data())

proxy.set_category_filter("All Categories")
proxy.set_search_text("")
print(proxy.rowCount())
```
