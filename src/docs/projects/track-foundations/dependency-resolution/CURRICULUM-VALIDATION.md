# Curriculum Validation

> Generated by `scripts/concept-graph-resolve.mjs` from `CONCEPT-GRAPH.md`.
> Do not hand-edit — re-run the script after any change to the graph.

For every `track/` lesson, checks that every `Required prerequisite` of
a node that lesson *introduces* was itself introduced at or before that
same lesson. Findings are classified into three severities:

- **Structural error** — a cycle or a dangling reference (from the
  shared graph validator). Fails the build.
- **Curriculum warning** — a genuine forward reference in `track/`'s
  lesson order: the graph says a lesson relies on something not
  introduced until later. `track/` itself is immutable and is not being
  "fixed" — but the new foundation curriculum is not obligated to
  reproduce this gap. Treat the graph, not `track/`'s original lesson
  numbering, as authoritative for how foundation material gets ordered.
  Review during Stage 6/7 lesson grouping.
- **Informational** — a historical quirk: Lesson 0 (`track/`'s own
  assumed-knowledge inventory, not sequential teaching) or a lesson
  explicitly annotated `(sighted only)`/`(assumed...)` in the graph
  itself. No action implied.
