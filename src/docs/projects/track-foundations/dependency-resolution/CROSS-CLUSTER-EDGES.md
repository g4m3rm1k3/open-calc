A cluster-level dependency graph: for every pair of clusters (see
`CONCEPT-CLUSTERS.md`) where a node in one is a `Required prerequisite`
of a node in the other, one row records which concepts carry that
dependency. Edges to/from single-node (non-clustered) concepts are not
included — those are already fully covered by `CANONICAL-ORDER.md` and
`DEPENDENCY-LEVELS.md`; this artifact exists specifically to let Stage 6
partition *clusters* into modules while minimizing cross-module
prerequisite edges, preserving conceptual cohesion within each module.
