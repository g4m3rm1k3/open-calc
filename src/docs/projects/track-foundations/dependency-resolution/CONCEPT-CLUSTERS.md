## Stage 6 partitioning rule

Clusters larger than 10 nodes are flagged below for
human review, never split automatically by this script. The rule for
any such split:

> **Large connected components may be subdivided only along weak
> dependency cuts, never by node count alone.**

A weak cut is a point in the cluster where few edges cross — i.e. the
two halves are each internally dense but only lightly connected to each
other. That's a teaching-strata boundary (e.g. "programming primitives"
vs. "object-oriented thinking" vs. "program execution" inside a large
orientation-lesson cluster); a cut chosen purely to hit a target node
count is not.
