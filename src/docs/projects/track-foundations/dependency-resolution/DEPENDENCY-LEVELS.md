Layer 0 holds every node with no `Required prerequisites`. Layer N holds
every node whose deepest required-prerequisite chain is exactly N steps
long — `layer(node) = 1 + max(layer(p) for p in Required prerequisites)`.
Useful for visualization and for sanity-checking that early lessons stay
in low layers.
